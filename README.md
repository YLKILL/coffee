# Сова Coffee

Адаптивный одностраничный сайт кофейни на React, TypeScript, Vite и Tailwind CSS.

## Возможности

- адаптивная навигация;
- переключение категорий меню;
- доступное модальное окно бронирования;
- встроенная карта и контактный блок;
- поддержка клавиатурной навигации и `prefers-reduced-motion`.

## Локальный запуск

Требуются Node.js 22 и pnpm.

```bash
corepack enable
pnpm install
pnpm dev
```

После запуска сайт будет доступен по адресу, указанному Vite в терминале.

## Production-сборка

```bash
pnpm build
pnpm preview
```

## Проверка типов и форматирования

```bash
pnpm exec tsc --noEmit
pnpm exec oxfmt --check src index.html vite.config.ts
```

## Важно перед публикацией

Контактные данные и ссылка Instagram в проекте демонстрационные. Форма бронирования показывает локальное подтверждение и пока не подключена к серверу или CRM.
